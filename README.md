Simple & Complex Vending

Simple & Complex Vending is a web application developed for a vending machine business offering a wide variety of snacks and drinks since 2023. This project serves as a communication tool for the company to engage with customers and businesses. It allows customers to provide feedback, while also enabling the company to communicate with potential business partners.

The frontend of the application is built using **Bootstrap** for responsive, modern UI components, but also includes custom **HTML**, **CSS**, and **JavaScript** to create an interactive and engaging user experience. On the backend, **Node.js** with **Express** is used to handle the server-side logic and API endpoints, while **MongoDB** serves as the NoSQL database for storing customer feedback and other business-related data.

## 🛠 Tech Stack

This project is built with the following technologies:

- **Frontend**: The user interface is designed with **HTML**, **CSS**, and **JavaScript**. **Bootstrap** is used for a responsive layout and modern UI components. Custom CSS is applied to give the application its own unique look and feel.
- **Backend**: The server-side is powered by **Node.js**, using **Express** to manage routes and API endpoints. The database is **MongoDB**, which stores customer feedback and other related data, and **Mongoose** is used to interact with MongoDB via an Object Data Modeling (ODM) approach.
- **Tools**: For local development, **Postman** is used to test API endpoints, and **Nodemon** is employed for automatic server restarts during development. **Dotenv** helps manage environment variables, such as the MongoDB URI, in a secure manner.
